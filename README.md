# mac-setup

My public Mac setup repo: small utilities and config for my Macs. It is the macOS
counterpart of [omarchy-setup](https://github.com/zoan37/omarchy-setup), which covers
my Omarchy machines.

## What's here

- [**Stay Awake**](stay-awake/) is a menu-bar mug that keeps the Mac awake, like
  Omarchy's coffee icon. Click the mug to toggle. While on, it holds the same power
  assertions as `caffeinate -dims`, and it comes back in the last state after a reboot.
  Build and install with `make install` from [`stay-awake/`](stay-awake/).
